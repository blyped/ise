> verticales. Un ecran n'est **jamais** declare `termine` avant que sa ligne soit complete et que la

suffixe commun.

## Regles d'usage de cette matrice

1. Une ligne passe en `en cours` quand la tranche verticale demarre, jamais avant.
2. Les colonnes `Tables`, `RLS`, `Mutations` sont renseignees **au moment ou le code est ecrit**,
   pas retroactivement.
3. Une ligne ne passe `termine` que si : UI conforme a la maquette · responsive 375/768/1024/1440 ·
   donnees reelles issues de la base · etats loading/empty/error/unauthorized · permissions verifiees
   serveur · validation client + serveur · mutations atomiques · accessibilite clavier et lecteur
   d'ecran · test E2E vert · aucune erreur console · aucun TODO critique.
4. Toute derive par rapport a la maquette est consignee dans `docs/decisions.md`, jamais laissee
   implicite.
